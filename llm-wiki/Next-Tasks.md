## 열린 과제

### 1. 새 리포지토리로 이전 — 커밋 히스토리에 남은 원본 데이터 제거
**무엇** — 현재 원격(`fomula91/sympo-studio`, public)의 커밋 `aa065d4` diff에 실존으로 보이는 의료인·의약품·행사장 데이터가 남아 있다. 워킹 트리는 가상 세트로 교체 완료했으나 히스토리 조회로 원본이 그대로 보인다. 커밋이 3개뿐이므로 히스토리 재작성보다 새 리포지토리로 시작하는 편이 깔끔하다.
**왜** — 의료인 실명·소속 공개, 특정 제약사 행사 특정 가능성, 업무상 저작물 범위 — 포트폴리오 공개 전에 닫아야 하는 리스크다.
**완료 기준** — 새 public 리포에 가상 데이터 상태로 초기 커밋, 기존 리포 비공개 전환 또는 삭제. `git log -S`로 원본 문자열 검색 시 0건. 이번에 하지 않는 것: README 재작성(별도 과제).

### 2. (예시) 첫 과제 제목 — 완료 기준까지 한 줄로 요약되게
**무엇** — 무엇을 만들/바꿀 것인가. 범위(어느 파일/흐름까지)를 명시.
**왜** — 어떤 위험을 줄이는가 / 왜 지금인가.
**완료 기준** — 관찰 가능한 결과로: 어떤 테스트/명령이 통과하면 끝인가. 이번에 하지 않는 것도 명시.
