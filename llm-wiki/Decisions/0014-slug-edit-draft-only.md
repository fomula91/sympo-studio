# 0014 — 공개 주소(slug)는 초안일 때만 바꿀 수 있다 — 옛 주소는 리다이렉트하지 않는다

## 상태
채택

## 맥락

`PATCH /api/events/[id]`는 slug를 **의도적으로** 바꾸지 않았다 — 공개된 뒤 주소가 바뀌면
이미 돌린 초대 문자·QR의 링크가 깨진다. 그런데 자동 slug(`행사명첫단어-장소-날짜`)는
길거나 어색할 때가 있고, 운영자가 공유하기 좋은 주소로 고칠 수단이 없었다(PR #68 요청).

허용 조건 후보는 셋이었다.
- ⓐ **상태가 `초안`일 때만** — 마이그레이션 없음.
- ⓑ **한 번도 공개된 적 없을 때만** — 첫 공개 시각 컬럼(`first_published_at`) 마이그레이션 +
  공개로 바뀌는 모든 경로(PATCH·POST·가져오기)에서 기록.
- ⓒ **언제든 + 옛 주소를 새 주소로 리다이렉트** — 별칭 테이블 + `/[slug]`·`/api/public/[slug]`·
  리포트의 별칭 조회, 별칭과 새 slug의 충돌 관리.

## 결정

**ⓐ를 채택한다.** slug는 상태가 `초안`일 때만 PATCH로 바꿀 수 있고, 옛 주소는 아무 처리도
하지 않는다(초안의 공개 페이지는 원래 404다). 공용 데모는 상태와 무관하게 주소를 못 바꾼다.

검증 규칙(`lib/slug.ts`가 정본, POST·PATCH·가져오기가 공유):
- **형식** — `^[a-z0-9][a-z0-9-]{0,79}$` → 위반 400.
- **예약어** — 최상위 정적 경로(`api`·`asset`·`console`·`events`·`intro`·`report`)와 데모 주소 →
  400. 정적 라우트에 가려 참가자 페이지가 안 열리기 때문이다. `lib/slug.test.ts`가 `app/`을
  훑어 예약어 목록의 누락을 잡는다.
- **중복** — PATCH는 접미사를 붙이지 않고 **409**(운영자가 고른 주소를 서버가 바꾸면 공유한
  주소와 실제 주소가 어긋난다). POST는 지금처럼 `-2` 접미사(회차를 여러 번 만드는 정상 흐름).
- **상태** — 초안이 아니면 403, 공용 데모면 403. 같은 값을 다시 보내면 상태와 무관하게 통과.
  읽은 뒤 쓰기 전에 공개로 바뀌는 경합은 `UPDATE … WHERE status = '초안'`으로 막는다.

## 근거

- ⓒ는 사용자 판단으로 기각 — "너무 친절한 선택". 이 서비스의 주소는 회차별 고유 주소이고,
  별칭까지 관리할 만큼 주소 변경이 잦지 않다. 작업량(테이블·리다이렉트 세 곳·충돌 규칙)도 가장 크다.
- ⓑ는 ⓐ의 위험(아래)을 원천 차단하지만 운영 D1 마이그레이션과 공개 경로 세 곳의 기록이 든다.
  사용자는 그 위험을 확인한 뒤, 차단 대신 **에디터 경고로 운영자에게 판단을 맡기는** 쪽을 골랐다.
- 주소를 바꾸고 싶은 순간의 대부분은 **처음 만들고 아직 공개하기 전**이다 — ⓐ로 충분히 덮인다.

## 결과·트레이드오프

**얻는 것** — 공개 전 주소를 자유롭게 고칠 수 있다. 마이그레이션 없음. 생성 경로(POST)의
slug도 처음으로 형식·예약어 검사를 받는다(예전엔 `str()`만 거쳐 공백·슬래시가 든 열 수 없는
주소가 저장될 수 있었다).

**감수하는 것 (정직하게)** — **공개 → "비공개로 전환"(초안) → 주소 변경**이 가능하다. 서버는
그 주소가 공유됐었는지 모르므로, 이미 돌린 초대 문자·QR의 링크는 404가 된다. 403 사유 문구가
"초안으로 되돌리면 바꿀 수 있지만, 이미 공유한 링크는 열리지 않게 됩니다"라고 알리고, 에디터
입력칸(FE-47)이 같은 경고를 항상 보여준다.

공개 응답의 짧은 `Cache-Control`(`/api/public/[slug]` 10초)은 영향이 없다 — 주소를 바꾸는
순간 이벤트는 초안이라 옛 주소·새 주소 모두 공개 페이지가 원래 404다.

## 재검토 트리거

- "공개 후 주소를 바꿨더니 공유 링크가 깨졌다"는 사고가 실제로 나면 → ⓑ(첫 공개 시각으로 고정)로 좁힌다.
- 공개 후 주소 변경이 정상 업무로 자주 필요해지면 → ⓒ(리다이렉트)를 다시 본다.
- `app/`에 최상위 정적 경로가 늘면 → `RESERVED_SLUGS`에 더한다(테스트가 잡는다).
