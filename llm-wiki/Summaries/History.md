## ⑤ 참가자 화면이 서버에 붙다 (9/1 ~ 9/3)

이 프로젝트에서 가장 큰 전환점.

- **참가자 공개 페이지 `/[slug]` 신설** — Q&A가 실제 D1 이벤트에 연결됐다. `PUBLIC_EVENT_ID=1` 하드코딩(스튜디오 목업 id와 D1 실제 id가 연결된 적이 없어 생긴 임시값)이 여기서 해소
- 이벤트 로그 적재 + 집계 API + 30일 보존 Cron
- 참가자 경로 **공개 상태 게이트** + 질문 모더레이션
- R2 자료 저장 + 업로드 + 서명 URL. **결제 수단을 등록해야 해서** 안전장치가 "카드 미등록"에서 **"사용량 알람 + 코드 상한"**으로 바뀜
- **실측 리포트 뷰 `/[slug]/report` 신설** — 스튜디오 리포트가 로컬 목업이라 실제 이벤트에 연결할 수 없다는 걸 착수 중에 발견하고, 별도 라우트로 우회
- **"주인 없는 계약" 발견** — 리포트는 읽는 쪽만 만들어졌고 **로그를 보내는 쪽을 아무도 자기 일로 적지 않았다.** 과제 분할이 만든 구멍이라 FE-20을 신설해 메움
