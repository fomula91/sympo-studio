## 지금 가장 중요한 사실

**백엔드는 거의 다 끝났는데 운영자 화면이 서버에 붙은 적이 없다.**

| | 서버 연결 | 상태 |
|---|---|---|
| 참가자 페이지 `/[slug]` | ✅ 붙음 | 아젠다·자료(PDF 뷰어)·Q&A·설문·수료증·열람 로그까지 실제 D1 |
| 참가자 리포트 `/[slug]/report` | ✅ 붙음 | 실측 집계를 그림 |
| 운영자 콘솔 `/console` | ❌ **0건** | 로컬 목업만 고침 |
| 운영자 에디터 `/events/[id]/edit` | ❌ **0건** | 〃 |
| 운영자 리포트 `/report` | ❌ **0건** | 〃 |

스튜디오 화면 5개 전부 `fetch` 호출이 **한 줄도 없다**. 열린 과제 중 **FE-15·FE-19·FE-23·FE-24·FE-25 다섯 개가 전부 이 하나의 원인**에서 나온다 — 개별 버그가 아니라 구조적 미연결이다.

→ **이 연결을 뚫는 것이 FE-30으로 등록돼 있고, 지금의 Next-Task 1번이다.** 그게 정해지기 전에는 위 다섯 과제를 개별로 잡아도 같은 벽에 다시 부딪힌다 → [[Summaries/Next]]

## 무엇이 돌아가는가

**서버 (전부 프로덕션 실측 완료)**
- 이벤트 CRUD · 참가자 공개 조회 · Q&A · 설문(수집·집계) · 아젠다/자료 저장 · 자료 파일 업로드(R2) · 열람 로그·집계 · 브랜드 프리셋 · Google 로그인
- API 라우트 18개, 마이그레이션 9개, 자정 Cron(데모 리셋 + R2 고아 정리 + 만료 세션 정리)
- rate limit 2층(브라우저 토큰 + IP 총량), 이벤트 소유권 검사

**참가자 화면**
- 아젠다 · 강의자료 PDF 뷰어(페이지 이동·확대) · Q&A · 설문 · 수료증 PDF · 오프라인 대응 · 열람 로그 4종

**배포**
- GitHub Actions — PR마다 검증(`verify`), `main` 머지 시 자동 배포

## 무엇이 안 되는가

- **운영자 스튜디오 전체가 목업** — 위 표 참조
- **「공개하기」 버튼이 공개를 안 한다** — 미리보기 오버레이만 열림(FE-23)
- **참가자 화면 탭바가 장식** — `onClick`이 없어 탭 전환이 안 됨(FE-17)
- **키비주얼이 `blob:` URL** — 새로고침하면 깨지고 서버로 보낼 수 없음(FE-19)
- **자동 테스트가 얇다** — 3파일 23건(`lib/`의 순수 함수만). 컴포넌트 테스트는 도입했다가 우선순위 판단으로 리젝(FE-22)
- **서버에 인가 구멍이 남아 있다** — 이벤트 상세·운영 지표 조회가 무인증(BE-24), 프리셋을 아무나 덮어씀(BE-25), 업로드에 rate limit 0건(BE-29). 2026-09-14에 코드로 재확인해 등록 — 같은 날 **BE-26(계정이 이메일로 자동 연결되던 것)은 닫혔다**([[Decisions/0010-account-link-key]])
