## 지금 가장 중요한 사실

**백엔드는 거의 다 끝났고, 운영자 에디터가 이제 그 일부(기본 정보)에 붙었다 — 아젠다·자료는 아직 목업이다.**

| | 서버 연결 | 상태 |
|---|---|---|
| 참가자 페이지 `/[slug]` | ✅ 붙음 | 아젠다·자료(PDF 뷰어)·Q&A·설문·수료증·열람 로그까지 실제 D1 |
| 참가자 리포트 `/[slug]/report` | ✅ 붙음 | 실측 집계를 그림 |
| 운영자 콘솔 `/console` | ❌ **0건** | 로컬 목업만 고침 |
| 운영자 에디터 `/events/[id]/edit` | 🟡 **부분** | 기본 정보(제목·장소·일시·좌장·인원·테마·참여 토글)만 실제 D1. 아젠다·자료는 로컬 목업 |
| 운영자 리포트 `/report` | ❌ **0건** | 로컬 목업만 고침 |

FE-30(스튜디오↔D1 연결 경로)이 **id 지목 방식으로 종료**됐다([[0010-studio-d1-slug-designation]]) — 에디터가 URL의 이벤트 id로 실제 D1 행을 읽고 기본 정보 편집을 저장한다. 열려 있던 **FE-15·FE-19·FE-23·FE-24·FE-25**는 더 이상 이 벽에 막혀 있지 않지만, 아젠다·자료까지 서버에 반영하는 건 여전히 각 과제(FE-24·FE-25)의 몫이다 → [[Summaries/Next]]

## 무엇이 돌아가는가

**서버 (전부 프로덕션 실측 완료)**
- 이벤트 CRUD · 참가자 공개 조회 · Q&A · 설문(수집·집계) · 아젠다/자료 저장 · 자료 파일 업로드(R2) · 열람 로그·집계 · 브랜드 프리셋 · Google 로그인
- API 라우트 20개, 마이그레이션 13개(번호는 0015까지 — 0007·0011은 결번), 자정 Cron(데모 리셋 + R2 고아 정리 + 만료 세션 정리)
- rate limit 2층(브라우저 토큰 + IP 총량), 이벤트 소유권 검사

**참가자 화면**
- 아젠다 · 강의자료 PDF 뷰어(페이지 이동·확대) · Q&A · 설문 · 수료증 PDF · 오프라인 대응 · 열람 로그 4종

**배포**
- GitHub Actions — PR마다 검증(`verify`), `main` 머지 시 자동 배포

## 무엇이 안 되는가

- **운영자 스튜디오는 기본 정보만 연결, 아젠다·자료는 아직 목업** — 위 표 참조
- **「공개하기」 버튼이 공개를 안 한다** — 미리보기 오버레이만 열림(FE-23)
- **참가자 화면 탭바가 장식** — `onClick`이 없어 탭 전환이 안 됨(FE-17)
- **키비주얼이 `blob:` URL** — 새로고침하면 깨지고 서버로 보낼 수 없음(FE-19)
- **자동 테스트가 여전히 서버 쪽뿐이다** — 11파일 83건(`lib/`의 순수 함수 + 가짜 D1으로 발행 SQL을 고정하는 것들). 가짜 D1은 **SQL 문자열만 보므로** 의미 검증은 로컬 D1 실측으로 보완한다. 컴포넌트 테스트는 도입했다가 우선순위 판단으로 리젝(FE-22)
- **서버 인가 구멍은 닫혔다** — 무인증 읽기(BE-24)·프리셋 덮어쓰기(BE-25)·운영자 쓰기 경계(BE-13)가 전부 종료됐다. **BE-26**(계정이 이메일로 자동 연결되던 것, [[Decisions/0011-account-link-key]])과 **BE-29**(업로드 상한 0건 → 파일 20MB·이벤트 300MB·5분 200MB 세 겹)는 닫혔다. 남은 원리적 한계는 **무효 요청 플러드**로, 애플리케이션 층에서는 못 막고 엣지가 맞는 층이다(BE-22)
